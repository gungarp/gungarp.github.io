## 📘 Overview
Welcome to agent-runner, a modular and production-ready framework designed to help you run Claude agents in automated workflows. With this tool, you can schedule tasks, send notifications, track costs, and easily integrate with AWS Bedrock.

## 🔍 Key Features
- Run agents in a flexible and organized way.
- Schedule jobs using cron or services.
- Receive Slack notifications for important updates.
- Simple cost tracking for your projects.
- Easy integration with AWS Bedrock for enhanced capabilities.

## 🛠️ System Requirements
To successfully run agent-runner, ensure your system meets the following requirements:

- **Operating System**: Windows, macOS, or Linux
- **Python**: Version 3.8 or higher
- **Memory**: At least 2 GB of RAM
- **Disk Space**: Minimum of 100 MB free space
